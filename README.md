# Искра — тренажёр системного аналитика

Интерактивный тренажёр для отработки блоков курса системного аналитика. Сквозной кейс — сеть автосервисов «Искра»
(7 станций в Казани) и студия разработки «Орбита», где вы — младший системный аналитик. Проект «Искра Онлайн»:
онлайн-запись, согласование доп. работ в приложении, онлайн-оплата — к весеннему сезону «переобувки».

Тренировки идут ровно по занятиям курса — 4 модуля, 24 тренировки:

- **Модуль 1 · Основы разработки.** Программа, приложение, система и сервис; жизненный цикл разработки; команда и роль
  аналитика; Waterfall, Scrum, Kanban; работа с разработчиками; работа с QA.
- **Модуль 2 · Требования.** Виды требований; User Story и Use Case; нефункциональные требования; работа с требованиями;
  работа с бизнесом (интервью); приоритизация и ценность фичи.
- **Модуль 3 · Моделирование.** CJM и user flow; интерфейсные требования и Figma; BPMN — базовый и продвинутый уровни;
  UML Sequence; UML Component.
- **Модуль 4 · Данные.** Реляционная модель; ERD; проектирование данных; Data Dictionary; SQL на живой базе;
  краткая выжимка перед собеседованием.

Каждая тренировка: «1. Теория» — живые разделы «Как это работает», «2. Практика» — задания с проверкой, разбором и эталоном.
Кнопка «Система» — карта компонентов «Искра Онлайн», настоящая база SQLite в браузере с SQL-консолью, модели статусов и
бизнес-правила.

Прогресс хранится в браузере. Отчёт для преподавателя — кнопка «Отчёт» вверху страницы. Режим преподавателя (все задания
открыты, эталоны без штрафа) — кодовое слово в разделе «Для преподавателя» внутри отчёта.

Встраивается в платформу ampschool.ru по протоколу `trainer/1` (как «Колос»): id задания платформы = id тренировки
(`m1-software` … `m4-interview`).

## Запуск

Статический сайт без сборки: откройте `index.html` или опубликуйте папку на GitHub Pages. SQL-движок (sql.js) и шрифты
грузятся с CDN — нужен интернет.

## Разработка

- `_dev/CONTRACT.md` — контракт модуля тренировки, `_dev/CASE.md` — кейс (люди, правила, статусы), `_dev/PLAN.md` — план.
- `bash _dev/test.sh [id …]` — автотест в headless Chrome; `bash _dev/shot.sh <id|home|system> [ширина] [высота] [light]` —
  скриншот; `bash _dev/sql.sh "SELECT …"` — запрос к базе «Искры».
